## 2. 케이스별 상세 (TC마다 1세트)

아래 표는 **엑셀/워드에 붙여넣기**에 맞게 한 행=한 필드다. **테스트 ID·테스트 일자** 는 케이스마다 덮어쓴다.

### TC-MS-A-001

| 항목 | 내용 |
|------|------|
| **테스트 ID** | TC-MS-A-001 |
| **테스트 일자** | (실시 시 기입) |
| **테스트 목적** | 4×4 격자에 빈칸(`0`)이 **정확히 2개**일 때, `find_blank_coords`가 **올바른 좌표 2개**를 반환하는지 확인한다. |
| **테스트 기능** | 빈칸 찾기 `find_blank_coords` — 정상(2빈칸) |
| **입력값** | 4×4 정수 격자. `0` 위치 예: (1,3), (3,3) (명세의 좌표 체계에 맞게 구현과 동일하게 해석) |
| **전제 조건** | 4×4 구조, 값은 규칙에 맞는 수로 구성 가능. |
| **성공 / 실패 기준** | **성공:** 반환 리스트가 `[(1,3), (3,3)]` 과 기대하는 순서(예: row-major)와 일치. **실패:** 누락·추가 좌표·순서 불일치. |
| **특별하게 필요한 절차** | 없음 (표준 unit 실행). |
| **테스트환경** | 로컬 개발 PC, Python 3.x, pytest(또는 팀 표준) |

**테스트 단계 (Given / When / Then)**

| 순서 | 내용 |
|------|------|
| 1 (Given) | 4×4 격자에 `0`이 (1,3), (3,3)에만 존재하는 입력을 준비한다. |
| 2 (When) | `find_blank_coords(격자)` 를 호출한다. |
| 3 (Then) | 반환값이 `[(1,3), (3,3)]` 이다 (명세·구현이 0/1-기반이면 동일 쌍으로 해석). |

**우선순위:** P1
